# Claude Fable (5.1) — `claude-fable-5-1`

**Rol:** opcional, máxima capacidad. Reservar para problemas que Opus no resuelva
o para trabajo creativo (naming, copy de producto, ideación de UX).

Coste alto: usarlo de forma explícita y puntual, nunca como modelo por defecto.
Para usarlo, define `model: claude-fable-5-1` en un agente o ejecuta `claude --model claude-fable-5-1`.
