# Glosario — Good Pizza

| Término                   | Definición                                                                                                                                                                                                                                     |
| ------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Administrador             | Rol que parametriza el sistema y gestiona los pedidos.                                                                                                                                                                                         |
| Cliente                   | Rol que se registra, arma pizzas, hace pedidos y consulta los suyos. No puede cancelar pedidos.                                                                                                                                                |
| Ingrediente               | Elemento del catálogo (incluye masa y salsa) con código, nombre, categoría, estado, stock, tarifa IVA y valores por tamaño. Solo se desactiva, nunca se borra.                                                                                 |
| Ingrediente inactivo      | Ingrediente desactivado: no se ofrece a clientes y se conserva en el histórico.                                                                                                                                                                |
| Categoría                 | Clasificación del ingrediente: masa, salsa, queso, carne, vegetal, otros.                                                                                                                                                                      |
| Masa                      | Ingrediente base obligatorio (exactamente 1 por pizza).                                                                                                                                                                                        |
| Salsa base                | Ingrediente base obligatorio (exactamente 1 por pizza).                                                                                                                                                                                        |
| Tamaño                    | Individual, Mediana o Familiar; determina calorías y precio por porción.                                                                                                                                                                       |
| Porción                   | Unidad de un ingrediente en una pizza; 1 porción descuenta 1 unidad de stock. Máximo 3 por ingrediente.                                                                                                                                        |
| Stock                     | Existencias de un ingrediente, medidas en porciones.                                                                                                                                                                                           |
| Pizza predefinida         | Una de 5 recetas del local (Margarita, Pepperoni, Hawaiana, Vegetariana, 4 Quesos). Se vende con su receta tal cual (incluso con menos de 3 ingredientes); el cliente solo puede agregarle ingredientes. Su precio sale siempre de la fórmula. |
| Predefinida no disponible | Predefinida con algún ingrediente de la receta inactivo o sin stock.                                                                                                                                                                           |
| Pizza personalizada       | Pizza armada desde cero por el cliente: tamaño, masa, salsa y mínimo 3 ingredientes distintos.                                                                                                                                                 |
| Receta                    | Conjunto de ingredientes y porciones de una predefinida.                                                                                                                                                                                       |
| Línea de pedido           | Pizza del pedido con su cantidad (1 a 20).                                                                                                                                                                                                     |
| Pedido / Orden            | Conjunto de pizzas confirmado por un cliente, con número, estado y totales.                                                                                                                                                                    |
| Número de orden           | Identificador `GP-AAAAMMDD-0001` (prefijo, fecha en zona horaria del servidor, secuencia diaria).                                                                                                                                              |
| Estado                    | Pendiente, En preparación o Entregado; solo el administrador lo cambia, sin retroceso.                                                                                                                                                         |
| Snapshot                  | Copia de precios, calorías y tarifa IVA guardada en el pedido al comprar.                                                                                                                                                                      |
| IVA                       | Impuesto al valor agregado; tarifas 15 % o 0 % por ingrediente.                                                                                                                                                                                |
| Subtotal 15 %             | Suma de componentes sin IVA con tarifa 15 %.                                                                                                                                                                                                   |
| Subtotal 0 %              | Suma de componentes sin IVA con tarifa 0 %.                                                                                                                                                                                                    |
| IVA 15 %                  | 15 % del Subtotal 15 %, redondeado a 2 decimales half-up.                                                                                                                                                                                      |
| Redondeo half-up          | Al llegar a la mitad se redondea hacia arriba (0,045 pasa a 0,05).                                                                                                                                                                             |
| Total                     | Subtotal 15 % + Subtotal 0 % + IVA 15 %.                                                                                                                                                                                                       |
| Comprobante               | Vista final de la orden, solo en pantalla (sin PDF ni impresión), con logo, datos, detalle por pizza y totales.                                                                                                                                |
| Seed                      | Carga de datos de ejemplo (usuarios, ingredientes, predefinidas).                                                                                                                                                                              |
| MoSCoW                    | Priorización: Must, Should, Could, Won't.                                                                                                                                                                                                      |
| Calorías                  | Energía por porción y tamaño; la suma por pizza se muestra en vivo.                                                                                                                                                                            |
