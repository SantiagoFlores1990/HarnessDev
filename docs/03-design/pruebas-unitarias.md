# Pruebas unitarias — Fase 3 (Diseño UX/UI)

## Alcance

En esta fase no hay código ejecutable. Las "pruebas" son **verificaciones de consistencia del diseño** contra los requisitos (`docs/01-requirements/`) y el contrato (`docs/02-architecture/api-contract.md`), realizadas **por revisión de los documentos y por cálculo manual** (los ratios de contraste se calcularon con la fórmula WCAG a mano; no se ejecutó ningún programa porque la fase no dispone de entorno de ejecución). Nada de lo marcado "OK" proviene de una herramienta automática; la verificación automática independiente se delega a las pruebas de widget WT-01..WT-xx de la sección 2, que `flutter-dev` debe implementar y ejecutar.

### 1.1 Cálculo manual de contraste (muestra reproducible)

Fórmula: linealización `c ≤ 0,03928 → c/12,92`, si no `((c+0,055)/1,055)^2,4`; `L = 0,2126 R + 0,7152 G + 0,0722 B`; razón `(L1+0,05)/(L2+0,05)`.

| Color                | Hex       | L (luminancia relativa) |
| -------------------- | --------- | ----------------------- |
| Blanco               | `#FFFFFF` | 1,0000                  |
| `primary`            | `#0A2A5E` | 0,0253                  |
| `surface`            | `#F8F9FD` | 0,9480                  |
| `onSurface`          | `#1A1C20` | 0,0115                  |
| `primaryContainer`   | `#D6E3FF` | 0,7646                  |
| `onPrimaryContainer` | `#001B3F` | 0,0114                  |
| `error`              | `#B3261E` | 0,1107                  |
| `warning`            | `#8A5A00` | 0,1272                  |
| `warningContainer`   | `#FFE8B8` | 0,8244                  |

Ejemplos: `#FFFFFF` sobre `#0A2A5E` = 1,05 / 0,0753 = **13,94:1**; `#0A2A5E` sobre `#F8F9FD` = 0,9980 / 0,0753 = **13,25:1**; `#8A5A00` sobre `#FFE8B8` = 0,8744 / 0,1772 = **4,94:1**.
